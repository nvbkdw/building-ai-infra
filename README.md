# Building AI Infrastructure

Source for [ryhuang.blog](https://www.ryhuang.blog) — Ryan H.'s notes on building AI infrastructure: GPU kernels, distributed training, LLM inference, and ML platforms.

Built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, with a layout modeled on [Lil'Log](https://lilianweng.github.io/) and a warm dark-brown color scheme. Deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Local development

```bash
hugo server            # http://localhost:1313, live reload
hugo new blogs/my-post.md
```

See `CLAUDE.md` for the project layout, customization points, and post conventions.
